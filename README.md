## 📌 Overview

**Ecslipe** is a high-performance frontend control panel built for tracking ad campaign metrics, filtering traffic (cloaking pass/fail status), and analyzing conversion rates through real-time charts and custom parameter filters.


## 📁 Project Structure

```text
ECSLIPE-MAIN/
├── css/             # Stylesheets and layout design themes
├── fonts/           # Custom web fonts
├── img/             # UI icons, SVG elements, and graphics
├── js/              # Interactive logic and Chart.js integration
├── actions.html     # Action logs and tracking interface
├── cloak.html       # Cloaking status & traffic filtering page
├── index.html       # Main analytics dashboard & charts page
├── profile.html     # User profile and account management
├── settings.html    # Configuration and settings page
└── README.md        # Project documentation
```
